# Help

## Rodando os testes

Escolha o seu sistema operacional:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Abra um Command Prompt.
2. Baixe o primeiro exercício:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Entre no diretório do exercício:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Rode os testes:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(Não se preocupe se os testes falharem no começo: é assim que você começa cada exercício.)_

5. Resolva o exercício. Encontre e siga o guia `instructions.append.md` ([ver no GitHub](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)).

Boa sorte! Divirta-se!

## Enviando sua solução

Você pode enviar sua solução usando o comando `exercism submit src/main/java/Lasagna.java`.
Esse comando vai enviar sua solução para o site do Exercism e imprimir a URL da página da solução.

É possível enviar uma solução incompleta, o que permite que você:

- Veja como outras pessoas resolveram o exercício
- Peça ajuda a um mentor

## Precisa de ajuda?

Se você quiser ajuda para resolver o exercício, confira as seguintes páginas:

- A [documentação da trilha Java](https://exercism.org/docs/tracks/java)
- A [categoria de programação da trilha Java no fórum](https://forum.exercism.org/c/programming/java)
- A [categoria de programação do Exercism no fórum](https://forum.exercism.org/c/programming/5)
- As [Perguntas frequentes](https://exercism.org/docs/using/faqs)

Caso esses recursos não sejam suficientes, você pode enviar sua solução (incompleta) para pedir mentoria.

Se você precisar de ajuda, pode visitar estes recursos:

- [Stack Overflow](https://stackoverflow.com/questions/tagged/java),
- [O subreddit do Java](https://www.reddit.com/r/java),
- [Documentação oficial do Java](https://docs.oracle.com/en/java/javase/11/docs/api/index.html).
